A web app can't read your calendar, so a Shortcut sends today's events to Echo each morning, before your briefing. Set it up once:

  1. Tap Copy your link below.
  2. Open Shortcuts → Automation → + → Time of Day. Choose 6:45, Daily and Run Immediately, then Next → New Blank Automation.
  3. Add Find Calendar Events. Tap Add Filter and set it to Start Date · is today. Set Sort by to Start Date.
  4. Add Repeat with Each.
  5. Inside the repeat, add Text. Insert Repeat Item, tap it, choose Start Date, set the format to ISO 8601 and turn on Include Time. Type  |  then insert Repeat Item again and choose Title.
  6. After End Repeat, add Combine Text: Repeat Results with New Lines.
  7. Add Get Contents of URL. Paste your link, tap Show More, set Method to POST and Request Body to File, and pick Combined Text.
  8. Tap Done. To try it now, tap ▶ in the automation; this screen then shows how many events Echo got.

Power off Echo?
