# Echo Bots

Open the Bots tab. Phone bots work independently; Your Mac shows the roster and actual runs on your authenticated, paired Mac. Echo’s existing styling is preserved. The bottom pages are Echo, Today, Chat, Bots and Browser. More and highlighted World Intelligence are on Echo; Saved remains in More.

Start a task, follow its tool progress, read the result, Stop, or Follow up. Create/edit/remove up to six Phone roles. Reading roles cannot save memory or delegate nested bots. Echo Assistant uses the existing daily-work tools; calendar, browser, Shortcut and Mac buttons are prepared actions requiring your tap. Essential questions pause as Needs you.

The existing model/quota configuration is used. Configure the existing Upstash store for durable run history; temporary storage is identified on the page. Phone jobs have four-minute/eight-turn limits, one active run per account and four local workers. Duplicate request IDs cannot start a different goal. Stops and expired leases prevent new effects; interrupted jobs require an explicit new run.

Bots use Echo’s existing model, guarded tools and Browser. Paired Mac tasks use its native guarded runner. Separate browser computers or isolated containers are not provisioned.

Validation: npm test (132 tests); scripts/bots-ui-test.mjs runs Chromium/WebKit with Playwright available through normal module resolution or ECHO_BROWSER_DEPENDENCIES. ECHO_WEBKIT_EXECUTABLE may select an already installed WebKit binary. Synthetic models and temporary local servers are used; no microphone or real user tasks are invoked by these tests.
